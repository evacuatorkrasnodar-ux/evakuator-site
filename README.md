# 🚗 Эвакуатор Краснодар 24/7 — PWA сайт

Сайт эвакуаторной службы в Краснодаре, выполненный в современном стиле Apple Glass UI.  
Работает как обычный сайт и как приложение (PWA) на iPhone, Android, Windows и macOS.

---

## 🌐 Живая версия сайта
**https://<твой‑репозиторий>.github.io/**

---

## 📱 Возможности сайта

### ✔ Установка как приложение (PWA)
- Работает офлайн  
- Иконка на рабочем столе  
- Быстрый запуск  
- Автоматическое кеширование страниц  

### ✔ Отправка геолокации
Клиент может отправить:
- координаты  
- полный адрес (через Яндекс Геокодер)  
- ссылку для открытия в Яндекс.Навигаторе  

### ✔ Отправка заявок в VK
Все заявки автоматически отправляются администратору через VK API.

### ✔ Светлая / тёмная тема
Сохраняется в `localStorage`.

### ✔ Полная адаптация
Работает на:
- iPhone  
- Android  
- ПК  
- планшетах  
- браузерах Chrome / Safari / Edge / Яндекс
